Esta página mostra o que cada ferramenta realmente gerou no disco. Nada aqui adivinha caminho. Se o arquivo existe, aparece. Se não existe, fica marcado como indisponível.

Fluxo rápido

  1. source ~/.secrets
  2. ./run.sh
  3. ./scripts/serve_docs.sh
  4. Abrir http://localhost:8000

Rodar tudo

Processa todos os PDFs da pasta input/ e atualiza o manifesto da visualização.

./run.sh

Testar um PDF solto

Use qualquer PDF fora deste projeto e jogue a saída onde quiser.

source venv/bin/activate
python3 scripts/run_one.py \
  --tool marker \
  --input ~/Downloads/exemplo.pdf \
  --output ~/Desktop/pdf-tests

Aliases sugeridos

Se quiser deixar seu terminal mais prático:

alias pdfobs='cd ~/projetos/PDF_markdown_OCR_comparison'
alias pdfrun='cd ~/projetos/PDF_markdown_OCR_comparison && ./run.sh'
alias pdfview='cd ~/projetos/PDF_markdown_OCR_comparison && ./scripts/serve_docs.sh'
Leitura rápida: `document.md` = documento consolidado. `page_X.*` = saída por página.
Use `Marker` e `MinerU` quando quiser layout e figuras. Use `Docling` quando quiser markdown limpo.
